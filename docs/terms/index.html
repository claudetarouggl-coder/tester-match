利用規約

本規約は、テスターマッチ運営（以下「運営」）が提供するテスター相互マッチングサービス「テスターマッチ」（以下「本サービス」）の利用条件を定めるものです。本サービスを利用することで、本規約に同意したものとみなします。

第1条（適用）

本規約は、本サービスの利用に関する運営と利用者との間の一切の関係に適用されます。本サービスは無料のオープンβとして提供しており、内容は予告なく変更される場合があります。

第2条（アカウント）

本サービスへのログインは、GoogleまたはGitHubアカウントによるOAuth認証のみで行います。本サービスはパスワードを保持しません。利用者は1人につき1アカウントの利用を原則とし、複数アカウントを不正に使い分ける行為は禁止します。アカウントの管理責任は利用者本人が負うものとし、OAuth連携先アカウントの管理不備により生じた損害について運営は責任を負いません。

第3条（禁止事項）

利用者は、本サービスの利用にあたり、以下の行為を行ってはなりません。

  • 虚偽の内容でアプリを掲載する行為
  • テストを継続する意図がないにもかかわらずテスト参加を行う行為（クレジット目的の使い捨て参加等）
  • 他者のメールアドレスその他の個人情報を本人の同意なく登録・使用する行為
  • 本サービスまたは第三者のサーバー・ネットワークに過度な負荷をかける行為、スパム行為
  • 本サービスのリバースエンジニアリング、逆コンパイル、逆アセンブル、その他ソースコードの解析を試みる行為
  • 本サービスを通じて知り得た他の利用者の情報を、テスト参加の目的以外で利用する行為
  • 法令、公序良俗に違反する行為、または運営が不適切と判断する行為

第4条（クレジット）

本サービスでは、テストへの参加確認等に応じて「クレジット」が付与されます。オープンβ期間中、クレジットは記録・表示されるのみで、クレジットの消費を必要とする機能は提供していません（将来の機能で利用できるようになる予定です）。クレジットに関して、以下の点にご注意ください。

  • クレジットは金銭的価値を持たず、購入・換金・払い戻しの対象にはなりません。
  • クレジットを他の利用者へ譲渡することはできません。
  • 本サービスはβ期間中であり、クレジットの付与条件・消費条件・保有上限等の仕様は予告なく変更される場合があります。運営の判断により、不正な取得が確認された場合等に残高を調整することがあります。

第5条（掲載コンテンツの責任）

利用者が本サービスに掲載するアプリの情報、説明文、その他のコンテンツについては、掲載した利用者本人が一切の責任を負うものとします。運営は掲載内容の正確性、合法性、安全性について審査・保証を行いません。掲載アプリの利用に起因して生じたトラブルは、当事者間で解決するものとします。

第6条（サービスの変更・停止）

運営は、利用者への事前の通知なく、本サービスの内容を変更し、または提供を中断・終了することができるものとします。これにより利用者に損害が生じた場合であっても、運営は責任を負いません。

第7条（免責事項）

  • 本サービスは現状有姿で提供され、運営は本サービスの完全性、正確性、有用性等について一切保証しません。
  • 運営は、本サービスの利用によってGoogle Playのクローズドテスト要件が満たされること、または審査に通過することを保証するものではありません。テスト成立の可否はテスターの実際の行動や各プラットフォームの審査基準に依存します。
  • 本サービスはGoogle Play・Google LLCとは無関係の第三者が提供する非公式のサービスです。
  • 運営は、本サービスに関連して利用者に生じた損害について、運営の故意または重過失による場合を除き、一切の責任を負いません。

第8条（規約の変更）

運営は、必要と判断した場合に本規約を変更できるものとします。変更後の規約は、本ページに掲載した時点から効力を生じます。変更後も本サービスの利用を継続した場合、変更後の規約に同意したものとみなします。

第9条（準拠法）

本規約の解釈にあたっては日本法を準拠法とします。
